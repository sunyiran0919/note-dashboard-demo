# 笔记类型 · 供给与转化看板（演示版）

这是根据页面视觉和栏目结构制作的静态交互演示。所有数字、趋势、榜单笔记与作者均为合成示例，不连接原看板或任何内部数据源。

## 本地查看

直接打开 `index.html` 即可。若浏览器限制本地脚本，可在此目录运行任意静态文件服务器。

## GitHub Pages

把本目录提交到 GitHub 仓库默认分支，在仓库 **Settings → Pages** 中选择 **Deploy from a branch**，分支选择 `main`，目录选择 `/ (root)`。发布后可通过 GitHub Pages 地址访问。

## 已实现交互

- 九个顶栏栏目切换
- 日期区间选择与刷新
- 指标、分面、周期切换
- 专题目录定位
- Top50 排序和笔记类型筛选
- 数据状态说明

此演示不支持原看板的数据查询与实时更新。
